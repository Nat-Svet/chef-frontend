# Шеф в Кармане

Умный гастро-конструктор меню на **Expo (React Native) + TypeScript**.

## Запуск

```bash
npm start
```

Дальше:
- нажмите `w` — веб-превью в браузере
- отсканируйте QR в приложении **Expo Go** — телефон

```bash
npm run web
```

## Supabase

Скопируйте `.env.example` в `.env` и подставьте URL и anon-ключ проекта. Пока ключей нет, экраны работают на моках.
